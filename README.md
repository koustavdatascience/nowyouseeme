# nowyouseeme

A tiny browser magic trick: step out, save the background, step back in, and make a hand-framed patch of yourself disappear.

## Live demo

**Try it here:** https://nowyouseemee.pages.dev

Built with a webcam, MediaPipe hand tracking, and a little help from **Manus AI**.

```bash
pnpm install
pnpm dev
```

Allow the camera, capture an empty frame, then raise both hands to activate the cloak.
